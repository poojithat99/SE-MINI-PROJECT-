# AI-CMS — Code (Statement) Coverage Report

**Sprint:** Sprint 3 — Testing, Coverage and Final Submission  
**Status:** Pre-final local coverage baseline (1 November 2026); update after any later changes  
**Tool:** Coverage.py, recorded through Python `unittest` on Windows PowerShell  
**Scope:** `src,backend`; service-layer subset `src/services/*`

## Method

```powershell
python -m coverage run --branch --source=src,backend -m unittest discover -s tests -v
python -m coverage report -m
python -m coverage report -m --include="src/services/*"
python -m coverage json -o storage\part3_test_data\results\coverage.json
```

Statement coverage is computed using Coverage.py JSON totals, as **covered statements / measured statements**. The regular console table's `Cover` percentage is a **combined statement-and-branch value**, not the pure statement rate.

## Measured results

|---|---:|---:|---:|---:|---:|
| Overall (`src,backend`) | 1,856 | 676 | 1,180 | **63.58%** | 60% |
| Service layer (`src/services/*`) | 549 | 135 | 414 | **75.41%** | 71% |

**Observed result:** The service-layer statement coverage of **75.41%** exceeds the STP's specified **50% minimum service-layer line-coverage target**. This statement coverage measurement is the appropriate line/statement-based indicator; combined coverage is shown only for reconciliation to the raw terminal output.
